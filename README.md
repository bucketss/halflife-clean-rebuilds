## Half-Life Clean Map Recreations

Goal of the project is to provide clean rebuilds of all the maps from Half-Life, its expansions, and select mods that are ready for mappers and modders to use "out of the box".
 
Light settings, and non-default textures included.

`hlcsg -cliptype legacy` is recommended for HL's single-player maps.

Rebuilt from original `bsp` sources, expect some compile warnings.
